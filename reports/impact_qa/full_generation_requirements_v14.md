# 全量候选生成最低要求 v14

2026-09-19，先于新开发实验和保留集查看固定。适用范围是IMPACT可恢复的QA候选批量生产，不是发布人工金标准或宣布异常理解任务完成。沿用[复查协议](review_and_scale_protocol.md)的质量要求，新增[机器配置](../../configs/impact_qa/release_v14.json)和自动拒绝缺失证据的门槛程序。

## 必须满足的基本要求

| 项目 | 最低要求 | 验证依据 |
|---|---|---|
| GT来源 | 全部候选事实有原文件哈希、JSON指针和原值；机械核验100%通过 | 源引用核验、明确的确定性答案映射 |
| 视频与时段 | 视角、帧率、起止、手、对象及截止时刻一致；不引用未来证据 | PTS、媒体哈希、输入清单、证据帧 |
| 开放题 | 对象与时间唯一，问答直接自然；不扩写未证实的方向、力度、具体错因 | 逐题源审查和直接视觉证据审查 |
| MCQ | 恰有一个GT支持项，选项同维度且互斥，无同义重复；打乱正确项位置 | 代码验证＋语义检查；与开放题按同一事件计数 |
| 视觉可回答 | 冻结后保留候选至少95%具有可复核的具体视觉证据 | 直接看实际输入，先独立回答后揭示GT；模型答对不替代此项 |
| 整体质量 | 保留候选无需修改通过率总体≥95%，每拟放行题型≥90%，严重缺陷0 | S/V/T/Q/M/D逐维审查，未审核不算通过 |
| 样本覆盖 | 每拟放行题型至少30个不同事件，有限规模候选验收至少5trial/3参与者 | 冻结后未用于开发的trial；参与者数不等于跨参与者隔离 |
| 筛选透明 | 同时报生成数、保留数、弃题原因，抽查被筛事件；不只检查容易题 | 固定筛选规则、分层随机抽样、拒绝队列 |
| 稳定性 | 完成率≥99%；失败逐条记录、可重试；恢复不重复出题/覆盖版本 | 请求审计、恢复测试、版本/媒体哈希 |
| 隔离 | 当前GT不进入视觉复核/公开评测输入，跨split同trial泄漏0 | 字段与文件名检查、group manifest |

严重缺陷包括错答案、错误对象或时段、无依据的原因/纠正、ASR=-1误当操作异常、把演示先后写成强制顺序、MCQ多解及GT泄漏。任一项不能通过其他项的平均分抵消。

**这些数字是本项目工程门槛，不是论文作者阈值或实测质量。** 自动门槛读取证据记录；缺指标、缺冻结版本、只有模型自审均拒绝放行。研究代理直接看图可标agent-reviewed候选，不能伪称真人审查。正式测试集仍建议真人双审与仲裁，候选开发无需新增人为批准流程。

## 数据有限时如何执行

此前16trial/8参与者、总200–300题是较广覆盖目标。当前只有6个相对已查历史未暴露装配trial/5参与者，不能以历史暴露回归集凑16。此次明确较小的**候选生产**最低覆盖为每类型30事件、至少5trial/3参与者，保留原16/8目标并披露未达到情况；不得把小范围结果写成全任务泛化。该调整发生在保留集查看之前，不降低GT、视觉、语义或严重错误标准。若实际合格事件不足30，则该类型仍不放行，不能重复改写同一事件充数。

质量验收对象包括真实生产的开放题和MCQ、实际评测图像、冻结筛选器；不能用单独盲答成功代替完整链路验收。二元平衡子集任一答案建议不超过70%；非二元工具类也报告类别分布，偏斜数据可声明自然分布但不能称平衡评测。存在弃题时，对弃题另设分母审查。

## 题型优先级与异常目标

工具大类最先进入开发回归，当前8trial全部46个合资格normal拾取事件，来源全覆盖、不依据模型结果选样。其答案只到螺丝刀/扳手大类，不涉及刀头和工具选择是否正确。状态与实际顺序需先修复v13的部件混认和粗细标签对应；异常原因/纠正QA必须有具体行为偏离及正确做法的来源。

工具题放行仅代表工具理解子集可生成，不代表异常理解数据集完成。仅有异常属性、缺少具体机制时，保留源标签或待补证据，禁止为了数量编造错因。规范图中的边必须有来源与适用范围；观察顺序、手册展示顺序与强制工程顺序分别存储。

## 放行后

每批最多500事件，全量执行硬检查；分层抽10%且至少50事件复查，不足50全查；所有分歧另全查。严重错误立即暂停受影响题型，共享源映射/同步/泄漏错误暂停全部相关分片。保留原输出、拒绝记录及恢复点。
