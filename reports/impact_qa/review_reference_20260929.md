# IMPACT六类异常与A/B拆装审核速查

2026-09-29。A/B是两款角磨机配置，不是两种手持工具。以下为已有资料整理和项目工作判据；六类具体规则不冒称作者完整标注手册。

## 六类异常定义

| 类别 | 定义 | 容易误判的情况 |
|---|---|---|
| Temporal（时机／时间异常） | 违反已确认的时机或时长要求；或在可推进条件具备时持续停滞、反复无效操作。 | 先排除另一手有效工作、必要检查和对位；手悬空、持件或超过8秒都不能单独判错。 |
| Spatial（位置／方向异常） | 部件、工具的位置或方向违反适用的装配、配合或摆放要求。 | 必须知道应放哪里／应朝哪里；临时放置、换姿态、持工具伸入料盒不自动算错。 |
| Handling（操作／控制异常） | 当前阶段的抓持、支撑、控制或执行方式不符合要求，或出现可确认的操控失败。 | 看实际接触、滑脱、掉落或无效施力；徒手预拧、松后旋出、支撑和测试不能仅凭动作名称判错。 |
| Wrong part（部件选择错误） | 实际选择或使用的部件、紧固件身份／规格不适用于当前目标。 | 先确认实际件和所需件；正确部件拿早、方向不对或试配，不等于身份选错。 |
| Wrong tool（工具选择错误） | 实际施用的工具与已确认目标接口或该操作阶段不适配。 | 确认批头、紧固件和实际接触；仅拿起工具、拿着工具却用手指操作，不能单独判错。 |
| Procedural（步骤／前置条件异常） | 违反必要前置状态、遗漏必做步骤，或执行在当前装配状态下不成立的操作。 | 需要明确哪项前置条件未满足；允许独立步骤换序、试装和纠正，不按唯一演示顺序判错。 |

类别可多选，但分别需要证据。Correct要求当前范围可判断；视觉不足或要求不清不能自动选Correct。

## 工具与紧固件

| 型号／位置 | 固定关系 | 工具 |
|---|---|---|
| A 适配板两颗长螺丝 screw_adaptor_topleft/lowright | 配对应M4螺母，连接适配板和壳体 | 红黄十字改锥 |
| A 两颗轴承板螺丝 bearing_screw_topleft/lowright | 连接轴承板与壳体 | 绿黑Torx六瓣梅花改锥 |
| A 拨杆螺丝 screw_lever | 固定拨杆小组件；涉及弹簧、垫圈 | 绿黑Torx；精确叠放次序需近景 |
| A 轴端小锥齿轮保持螺母 | 将小齿轮保持在传动轴端 | 银色两用扳手；M4/M6冲突逐例核对 |
| B 已核对的轴承板螺丝 | 连接B轴承板与壳体 | 黑蓝一字改锥；不是所有B螺丝通用规则 |
| A/B 防振侧手柄 | 自身螺纹柱旋入壳体侧孔 | 徒手旋入／旋出，不是上述五颗螺丝固定 |

银色“小帮手”为两用扳手；Torx是六瓣梅花，不是内六角。工具颜色仅帮助识别。预拧、松后徒手旋出和支撑调整可能合理。

## A/B拆装过程

A型为Fein CG15-125BL，参考为黑壳；B型为Fein WSG7-115A，参考为银灰壳。A型以下顺序来自官方手册示范；独立步骤的合法换序不能直接判错。B型完整逐步操作细节尚未被同等级手册或逐目标证据确认，下面明确列出限制，不能把A的图复制为B的SOP。

### A型安装

| 步骤／对象 | 操作过程 | 依据与限制 |
|---|---|---|
| 1. 转子轴与小锥齿轮 | 将轴组件插入壳体对应通道，使小锥齿轮在轴端就位；内部保持螺母先手指就位，再用银色两用扳手紧固。 | A手册图示；M4/M6冲突需另审 |
| 2. 适配板 | 在转子入壳端对位适配板；两颗长螺丝分别配对应M4螺母，以红黄十字改锥操作螺丝端。两组连接均应检查。 | A手册与组件图 |
| 3. 轴承板 | 板组件及内侧大齿轮对位进入壳体；两颗轴承板螺丝用绿黑Torx紧固。外观贴合不证明内部啮合或扭矩合格。 | A手册与组件图 |
| 4. 锁紧拨杆组件 | 核对拨杆、弹簧、垫圈和拨杆螺丝；拨杆螺丝用绿黑Torx。垫圈／弹簧的精确叠放位置必须看近景，不能凭名称补全。 | A手册；叠放细节待逐例确认 |
| 5. 侧手柄与检查 | 用侧手柄自身螺纹柱旋入侧孔，徒手旋转；检查已操作连接与可见状态。手柄等独立步骤的相对次序可有变化。 | A手册；不是唯一合法全序 |

### A型拆卸

| 步骤／对象 | 操作过程 | 依据与限制 |
|---|---|---|
| 1. 侧手柄 | 扶稳壳体，旋出侧手柄并归置；手柄使用自身螺纹连接。 | A手册示范顺序 |
| 2. 锁紧拨杆组件 | 用绿黑Torx松拨杆螺丝，控制并收纳拨杆、弹簧、垫圈及螺丝，核查是否意外散落。 | A手册；不擅定小件叠放顺序 |
| 3. 轴承板 | 用绿黑Torx解除两颗轴承板螺丝，松动后允许徒手旋出，再取下板组件。 | A手册 |
| 4. 适配板连接 | 用红黄十字改锥解除两颗长螺丝与配套M4螺母的连接，控制小紧固件。 | A手册 |
| 5. 内部螺母与轴组件 | 齿轮腔可接近后，用银色扳手松保持螺母；取下对应小齿轮／螺母后分离轴组件和壳体，整理适配板。 | A手册；具体部件释放顺序以实际连接为准 |
| 6. 归置 | 按已明确的组件／工具存放要求归置；没有已知盒位规则时，不能仅凭暂放桌面判Spatial。 | A手册图示归置；盒位需现场说明 |

### B型安装

| 步骤／对象 | 操作过程 | 依据与限制 |
|---|---|---|
| 1. 识别B型零件与连接 | 使用B的银灰壳体、转子轴、小锥齿轮、轴承板、适配板和侧手柄；不默认存在A的拨杆小组件或适配板M4螺母对。 | 官方B爆炸图 |
| 2. 转子轴与保持连接 | 按B实际配合关系对位轴、小齿轮和保持紧固件。旋转轴不等于旋紧螺母；应核对相对运动和当前目标。 | 结构检查建议；无独立B逐步手册确认 |
| 3. 适配板 | 按B转子另一端的结构检查就位；不得把A的适配板固定关系或红黄十字工具要求直接移植过来。 | 官方B图；具体紧固细节未确认 |
| 4. 轴承板 | 检查配合与对应螺丝；同一一字槽螺丝应使用适配的一字批头，但B安装全过程与全部螺丝身份尚未逐一确认。 | B拆卸样例支持一字工具；装配为接口参照 |
| 5. 侧手柄与检查 | 手柄用自身螺纹柱连接侧孔；核查可见连接。B本地无ASR，不能显示为已确认装配完成。 | 部件图＋可见状态审核 |

### B型拆卸

| 步骤／对象 | 操作过程 | 依据与限制 |
|---|---|---|
| 1. 侧手柄与支撑 | 确认所转的是侧手柄还是轴／螺母；手柄可沿自身螺纹旋出，另一手稳定壳体。 | 部件图；相对步骤次序不固定 |
| 2. 轴承板 | 已核对B拆卸样例用黑蓝一字改锥松轴承板螺丝，再取下板；具体螺丝身份仍需当前视频确认。 | AL07EJ17_Disassembly_B_005，26.97s工具样例 |
| 3. 内部传动连接 | 露出内部后，确认保持螺母／小锥齿轮等阻挡连接已经解除，再检查轴组件如何分离；工具规格和紧固件不能凭A推定。 | 结构检查建议；细节未完整验证 |
| 4. 适配板与归置 | 按B结构检查适配板与轴组件的分离和存放；不要求执行A拨杆、弹簧、垫圈小组件步骤。 | 官方B图；不是完整B强制操作顺序 |

## 前端展示

7863在视频下显示拆装辅助卡：双手当前动作、当前步骤、组件状态、对应工具和顺序参照随播放时间更新；完整流程、工具外观、部件功能、六类定义按需展开。本题候选类别附针对性核验点及已有模型支持／反证／不足状态。该功能不新增模型判断、不自动判错。

1,977题中1,532题有ASR，445题没有（含全部432道B型候选及13道A型题）。无ASR不推断完成状态。ASR -1表示标注装配异常，0未安装，1已正确安装；均为可错的原标注。

工具参照对应紧固件类别，不证明当前泛称screw就是该实例。安装反向动作可能是纠正或试配；取放工具不证明已经用错工具。
