# IMPACT QA 人工审核界面

入口：`http://10.112.70.171:7860`（需要能访问服务器所在网络）。

默认显示v18中通过模型筛选的33组；选择“全部生成草稿（161）”可检查隔离题目，含151组工具拾取及10组观察顺序。每组同时展示开放式问题/生成答案、MCQ/正确项、GT参考答案。模型状态仅是此前筛选结果，人工结论单独记录。

播放器展示原始front视频的题目区间，H.264 MP4、保留原始分辨率，省略音轨。时间由原始帧区间/fps计算，右端采用最后一帧之后的边界；页面标出原录像绝对秒数。可勾选前后各扩展3秒，该模式只是辅助审查；页面另外标明播放器内真正的题目时间范围。模型此前实际看到的是抽帧及局部图，不是这里连续播放的整段视频，人工可用这一区别判断模型筛除是否过于保守。

操作：选择题目→播放视频→核对两种问答→填写审核结论、可选修正答案和备注→点击“保存审核”→上一条/下一条。切换题目前需保存；再次打开题目会载入最新保存内容。修改审核会追加历史，不覆盖此前记录。导出按钮下载全部人工审核历史JSONL。

人工记录保存在`outputs/impact_qa/human_review_v18/reviews.sqlite3`，视频缓存位于同目录`clips/`；原始QA/模型审核/冻结输入保持不变。可通过导出记录的contract_id关联原题，每条记录含审核人、UTC保存时间及原草稿hash。

启动：

```bash
cd /home/ldq/project/sop
.venv-review/bin/python scripts/serve_impact_review.py --port 7860
```

后台运行日志：`outputs/impact_qa/human_review_v18/server.log`；PID：同目录`server.pid`。依赖使用独立`.venv-review`，不修改`.venv-impact`或使用GPU。端口绑定`0.0.0.0:7860`，不创建Gradio公共转发链接。
