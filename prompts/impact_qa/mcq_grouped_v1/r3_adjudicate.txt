Audit the GT-targeted hand operation using the video, prior independent observation, action annotations, and model-specific reference. Perform TWO SEPARATE checks. GT supplies the proposed MCQ answer; it does not prove a visual explanation.

RULES: ACTION GROUNDING
1. Return action_grounding=matches only when the target hand visibly performs the annotated action on a compatible object during the stated interval, with 2–4 supporting frames spanning at least one second. Match the interaction, not just the presence of an object. Missing action identity, occlusion or another hand doing the work means uncertain. Direct contradiction means conflicts.
2. Check consistency with the blind observation's visible facts. Do not copy an annotation into the description if the pixels or blind facts do not establish it. A groundable operation can still have an anomaly type that cannot be independently verified. Use observation_consistency to record this distinction.

RULES: ANOMALY TYPE
3. For EACH label, supported requires a concrete visible fact and an applicable correctness criterion. The GT label itself is not that criterion. Otherwise use uncertain, or contradicted for direct contrary evidence. Explain observation + criterion in at most 45 words.
4. Cite frames inside BOTH the event AND that label's type_subintervals_in_source_frames. A merged ATR event can have different labels at different times. Never use evidence from the opposite hand or another label's subinterval.
5. Temporal needs a timing failure/sustained ineffective delay; Spatial needs inappropriate geometry; Handling needs grasp/manipulation difficulty; Wrong part/tool needs a known task requirement plus visibly incompatible selection/use; Procedural needs an applicable stated prerequisite and visible violation. Do not invent a unique operation order.
6. Bare-hand loosening is not automatically Wrong tool. Idle tool holding is not automatically Temporal. Co-holding while returning a part is not automatically Handling. Model A facts do not automatically apply to B; generic screws do not identify a specific receiver or matching tip.
7. reference_basis must identify visible_geometry, visible_interference, observed_timing, provided_domain_reference, or missing_reference. Confidence is qualitative, not a probability. A not_visible blind abnormality judgment can remain compatible with a grounded action, but cannot alone justify a type.

Examples: Visible hand-loosening with matching GT action -> action matches; if screw/tool requirement is unknown -> Wrong tool uncertain. GT says shaft rotation, but the target hand only stabilizes the housing -> action uncertain/conflicts; do not invent rotation. GT says Procedural and no prerequisite is supplied -> uncertain.
