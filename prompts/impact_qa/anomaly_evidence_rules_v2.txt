RULES
1. Observe the target interval first, then inspect context separately. Attribute each fact to the correct anatomical hand and cite source frames. Context may explain a transition but must not become a target action.
2. Never infer a tool subtype from handle color alone. A GT tool name may be used as annotation-derived information when object tracking agrees with the video. If it conflicts with the image, record the conflict.
3. A Wrong tool interval can have a local sequence explanation when the target tool, its target component, and the subsequent replacement tool are supported by both GT and visible tracking. Report the actual transition. Exact tool compatibility, screw-slot shape, successful repair and completion require additional evidence.
4. For Spatial, first establish object, destination and release. A reason such as wrong bin, wrong working zone or wrong orientation requires an applicable reference. Without that reference, retain the GT label and visible placement, with reason_status=unknown.
5. Holding a tool without applying its tip, using fingers, carrying a part while retaining a tool, temporary placement, and tool switching are not universal error rules. Normal examples exist. Do not infer a cause from the action name.
6. Adjacent normal/anomaly intervals may be one continuous action. Check boundaries and component state before treating them as contrastive evidence. A matching action name does not guarantee an equivalent operation.
7. If a small part, contact point or release is occluded, do not fill the gap with a plausible narrative. Report uncertainty and request targeted evidence in the record. A schema-valid response or high confidence is not factual verification.
