This is a project evidence policy, not an official IMPACT annotation rubric. Preserve native GT, visual observations and causal explanations separately.

RULES
1. Bind every claim to trial, view, anatomical hand and source-frame interval. Use that view's native GT. An approximate cross-view window is not a matched GT event. Do not copy front labels into ego or decide labels by majority vote.
2. Observe what is visible before explaining the supplied label. Cite target and context frames separately. Record tool identity, component identity/state, tool contact, destination, release and subsequent change. State which information comes only from GT.
3. Holding a screwdriver while storing a part is neither sufficient nor necessary for an anomaly. Do not create rules based only on empty holding, finger use, temporary table placement, repetition or tool switching.
4. A hand entering a bin does not establish release. The tool tip may point away from the bin while the fingers manipulate a part. Separate a hand trajectory, visible object transfer and verified final placement. If the small object is occluded, leave its exact release unknown.
5. For a Spatial explanation, require the observed object/destination AND an applicable placement reference for that component, state, model and step. A readable bin number identifies a destination; it does not define what belongs there. Subsequent relocation supports a local hypothesis, not automatically a verified correction or universal rule.
6. Match normal controls by object state and prerequisites, not just action name. A shaft with an attached plate differs from a shaft after plate removal. Adjacent normal/anomaly intervals can share a continuous movement. Flag incomplete, different-hand or conflicting controls.
7. For Wrong tool, describe a verified local tool-replacement sequence if available. Tool subtype requires GT/object tracking or identifiable tool geometry, not handle color alone. Do not invent screw-slot compatibility or successful repair. Temporal/Handling/Procedural/Wrong part labels also do not supply a threshold, mechanism or violated prerequisite by themselves.
8. On cross-view GT disagreement or unresolved visual evidence, keep the original annotations, record the conflict, and hold normative/cause QA. Never relabel uncertainty as Correct. High model confidence is not verification. Diagnostic short events are not automatically production-eligible.

FEW-SHOT
Normal GT + right hand retains a red/yellow screwdriver while reaching into Box 4: report the retained tool and bin-directed action; do not call tool retention an error or invent a visible screw release. Verified local example: LE07UF17_Disassembly_A_004, front 160.733–162.667 s, ego 161.175–163.101 s.
Spatial GT + a long fastener is visibly released on the grey tabletop while the screwdriver lies nearby: report tabletop placement and the GT category; without the applicable placement reference, cause remains unknown. Local example: LE06AS03_Disassembly_A_003, ego 124.253–125.818 s.
Spatial storage in Box 2, followed by normal storage with the hand moving from Box 2 toward Box 3: report both observed actions in their own intervals. If the screw cannot be tracked through the fingers, do not say the same screw was visibly retrieved and the error corrected. Local example: SS07EL13_Disassembly_B_005, ego 87.571–90.019 s and 94.434–95.316 s.

RECORD
gt: native annotation pointers and labels; observations: facts with view/hand/source frames; object_state; reference_rule: source or null; explanation: supported local account or null; reason_status: supported_local / hypothesis / unknown / annotation_disagreement / not_applicable; uncertainties; control_comparability. Normal describes only the supplied target scope, not the whole video or the other hand.
